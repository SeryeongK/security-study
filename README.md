# security-study

웹·암호·네트워크·AI·하드웨어 보안을 공부하며 남기는 풀이 기록입니다.
문제마다 **"개발자라면 어떻게 막을지"**까지 정리하는 것을 목표로 합니다.

## 공개 규칙

1. 플래그는 올리지 않습니다.
2. 문제 소스 전체를 복사하지 않습니다. 문제 링크를 걸고 취약한 부분만 인용합니다.
3. 진행 중인 CTF 문제는 올리지 않습니다. 종료 후 대회 규칙을 확인하고 올립니다.
4. 키·토큰 등 비밀 값은 올리지 않습니다.
5. 모든 실습은 워게임, 내 로컬 환경, 내 소유 기기에서만 진행합니다. 허락 없는 시스템 점검은 하지 않습니다.

## 구조

| 폴더 | 주제 |
| --- | --- |
| `web/` | 웹 해킹 - 인증·세션, 접근 제어, SQL 인젝션, XSS |
| `crypto/` | 암호 - 해시·HMAC·전자서명, 키 관리, 재전송 공격 |
| `network/` | 네트워크·산업 프로토콜 - Wireshark, MQTT, Modbus |
| `ics/` | ICS 보안 - MITRE ATT&CK for ICS, IEC 62443, 위협 모델링 |
| `ai/` | AI 보안 - 프롬프트 인젝션, 에이전트 도구 권한 |
| `hardware/` | IoT·하드웨어 - UART·SPI, 펌웨어 분석 |
| `mobile/` | 모바일 앱 분석 - APK, Frida |
| `labs/` | 로컬 실습 환경 (docker 등) |
| `templates/` | 풀이 기록 양식 |
